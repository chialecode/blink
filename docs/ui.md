# BLINK 界面规范

本页定义 `Windows + Android + Linux + macOS + iOS` 五端自适应布局（桌面端沉浸式无系统标题栏飞书式三栏与精简移动端）、中文阅读与笔记视觉排版令牌、**所见即所得 + 源代码双模式 Markdown 编辑器（含五条 CJK IME 组合态保护铁律）**、**双表面高表现力 HTML（Surface 1 原生组件树 + Surface 2 离线沙盒整页）**，以及核心视图和同步/AI 状态的交互契约。功能范围见[需求](requirements.md#scope)，产品交互决定见 [DEC-033](decisions.md#dec-033)、[DEC-034](decisions.md#dec-034)，客户端分层与状态管理见[系统架构](design/architecture.md#topology)，内容模型与底层格式契约见[数据与同步设计](design/data-and-sync.md#bfm)。

设计总则：

- **直觉化笔记心智、零黑话界面**：界面文案面向日常记笔记与阅读场景，使用**小记、笔记、待办、附件、设置、Markdown、数据文件夹、云端加密同步**等直观词汇，不向用户暴露“采集流”“BFM”“blobs/”“VACUUM INTO”“FTS5”“rev N”等内部工程术语；底层 BFM v1 扩展语法、原文只读层与 `#private` 四层隐私隔离继续无缝生效（[DEC-033](decisions.md#dec-033)）。
- **打开即写、阅读即沉浸**：启动默认落在**小记**聊天式闪念时间线（底部常驻胶囊输入框，像发消息一样秒记想法），**笔记**提供干净文档列表与所见即所得写作区，阅读进入沉浸伴读；首屏绝不堆叠统计仪表盘或复杂属性表单。
- **克制分区与单主按钮原则**：依靠浅暖/纯白底色对比与 `1px` 细分隔线划分层次，不堆叠多层嵌套阴影卡片；每个局部区域最多只放一个强调色主按钮，次要操作统一收进弹出式“⋯”更多菜单（桌面端锚定浮层、移动端底部操作抽屉，危险删除项红字分隔）。
- **原文与 AI 派生层视觉分明**：用户手写小记、笔记、高亮与人工批注采用实底正文样式；外置 AI（CLI/MCP）或可选内置直连 AI 产出的标签、跨时空回响（Echoes）、原则建议与**双表面高表现力 HTML 卡片/整页**统一采用 `surface.aiDerived` 微底色或编辑部信息卡片容器，带明确的 `✦ AI 派生` 来源微标与 `<blink-ref>` 可点击原文溯源胶囊（[DEC-024](decisions.md#dec-024)、[DEC-025](decisions.md#dec-025)），杜绝把机器生成文字混充为用户原话。
- **安静诚实的非阻塞状态**：常规“未配置同步”或“已同步”不占用全局顶部横幅（由桌面图标栏底部同步圆点与“设置 → 多端同步”诚实展示）；仅当出现**离线待传、对端离线/休眠、正在同步、同步冲突、扫描版 PDF 无文本层、Linux 降级、私密本地闭锁或报错**时，以安静的顶部/行内状态条呈现（配图标、文字与无障碍名称，不只靠颜色），绝不用全屏转圈遮罩打断输入或阅读。

## 1. 五端自适应窗口与飞书式三栏布局

单一 Flutter 视图树按视口有效宽度（逻辑像素 `dp` / `px`）分四档自适应切换**飞书式三栏桌面布局**与**极简流式移动布局**，任何档位严禁出现横向滚动条（`NFR-PLAT-001`）：

| 视口宽度档位 | 典型设备形态 | 左侧主功能图标栏 / 底栏 | 侧边栏资源栏（所有模块均有专属资源栏） | 右侧主面板 |
| --- | --- | --- | --- | --- |
| `≥ 1280px` | 桌面宽屏（Windows / macOS / Linux） | 左侧固定图标栏 **`60px`**（顶部品牌标；图标 + 2 字短标签；底部固定搜索、同步圆点、设置） | **`260px`**（按当前模块切换专属资源栏：小记筛选与标签 / 笔记目录与新建 / 待办状态筛选 / 附件分类 / **设置分类栏**；支持 `Ctrl/Cmd + \` 或收起按钮一键折叠） | 主工作区自适应居中限宽：小记聊天时间线 + 底部胶囊输入、笔记 Typora 风格所见即所得编辑器、待办列表、附件列表或**单项设置详情页**；伴读阶段默认正文 + 右侧边注分栏 |
| `960px～1279px` | 桌面标准窗 / 横屏大平板 | 左侧固定图标栏 **`60px`** | **`232px`**（全模块常驻且支持一键折叠；进入伴读沉浸态自动折叠让宽） | 同上，主面板居中自适应，无横向溢出 |
| `600px～959px` | 竖屏平板 / 折叠屏展开态 / 桌面窄窗（最小 `760×560`） | 左侧紧凑图标栏 **`52px`**（顶部带侧栏抽屉唤起钮） | 不常驻，点击抽屉按钮从左侧滑出当前模块的专属资源栏（设置页同时提供顶部紧凑分类切换条） | 单主视口居中展示；伴读边注以右侧滑出浮层呈现（点正文或按 `Esc` 收起） |
| `< 600px` | 手机竖屏（Android / iOS） | 底部精简四项导航栏 **`52px`**（**小记 / 笔记 / 待办 / 设置**；软键盘弹出、进入全屏笔记编辑或设置二级页时自动收起） | 无常驻侧栏；小记/笔记顶栏左侧轻点标题或筛选按钮打开筛选抽屉；设置首页即为干净分类列表 | 单焦点全宽视图：小记聊天流 + 单行底部胶囊输入栏；笔记列表点击推入全屏编辑器；设置点击推入单项详情页；附件管理位于 `设置 → 附件管理` 与编辑栏附件入口 |

窗口与壳层细节：

- **桌面端（Windows / macOS / Linux）**：采用沉浸式无系统原生标题栏设计（[DEC-034](decisions.md#dec-034)），无冗余顶栏 `AppBar`，不把 `DEV` 徽标放在主窗口顶栏（仅保留于“关于”页）；飞书式三栏（左侧主功能图标栏、侧边资源栏、右侧主面板）与栏间 `1px` 垂直分隔线直接从窗口最顶部贯通至底部，图标栏与资源栏固定不随正文滚动；各栏顶部 `44px` 空白区域支持拖拽移动窗口与双击最大化/还原，轻量窗口控制按钮（最小化 / 最大化或还原 / 关闭，关闭行为遵循“隐藏到托盘 / 直接退出”设置）融入主面板右上角并与顶栏操作、状态横幅保持清晰避让间距，同时保留原生边缘缩放与贴靠能力；全局快捷键统一为：`Ctrl/Cmd + N` 聚焦新建（小记输入框或新建笔记）、`Ctrl/Cmd + K` 全局搜索与跳转、`Ctrl/Cmd + /` 切换笔记编辑器的**所见即所得 / 源代码**模式、`Ctrl/Cmd + \` 折叠/展开侧边资源栏、`Ctrl/Cmd + S` 立即保存当前笔记、`Esc` 关闭浮层与抽屉。桌面最小窗口尺寸限制为 `760×560`，支持系统托盘后台常驻。
- **桌面端五入口与后续扩展**：左侧主功能图标栏自上而下为 **小记**、**笔记**、**待办**、**附件**，底部固定 **搜索**、**同步状态圆点**（点击直达 `设置 → 多端同步`，有冲突时直接打开冲突对比窗口）与 **设置**；后续 M5/M6 接入**书库**伴读与**回顾**视图时沿同一飞书三栏结构扩展，每个模块均具备独立资源栏。
- **移动端（Android / iOS）**：严格遵守状态栏、刘海/灵动岛与底部手势横条安全区（`SafeArea` + `MediaQuery.viewInsetsOf(context).bottom`）；顶部仅保留 `44px` 极简标题条，无冗余工具行；小记底部输入胶囊随软键盘平滑顶起、零抖动避让。

## 2. 视觉、配色、中文排版与编辑器 CJK 输入法保护令牌

整体视觉采用低噪耐看的纸感编辑部风格：避免刺眼高饱和色块，保证长时间中文阅读与夜间写作的视觉舒适度。所有颜色、字号、圆角与间距集中定义在 `blink_theme.dart` 令牌层（业务组件严禁出现硬编码色值字面量），**同时动态注入为 Surface 2 沙盒 HTML 的 `--blink-*` CSS 自定义属性**。

### 2.1 色彩语义令牌（同步映射为 Surface 2 `--blink-*` CSS 变量）

| 语义令牌（Surface 2 CSS 变量） | 日间值（Day） | 暖纸值（Sepia） | 夜间值（Dark） | 用途边界 |

### 2.2 字体、中文排版与编辑器五条 CJK IME 铁律（`SPK-02`）

| 场景 | 字体栈优先级 | 字号与字重 | 行高、版心与输入法保护约束 |
| --- | --- | --- | --- |
| 界面控件与导航 | `Inter` + 系统中文无衬线（Windows `Segoe UI` / `Microsoft YaHei UI`、macOS/iOS `PingFang SC`、Linux `Noto Sans CJK SC`、Android `HarmonyOS Sans SC` / `Roboto`） | 导航与正文 `14px`（400/500），分栏标题 `16px～18px`（600），微标与元信息 `12px` | 单行标签省略号截断；数字采用 `tabular-nums` 对齐时间、计数与页码 |
| 笔记所见即所得与源代码编辑 | 同上无衬线栈；代码块与行内代码采用 `JetBrains Mono` / 系统等宽栈 | 正文桌面 `15px`、移动 `16px`（防聚焦缩放），标题 H1 `26px` / H2 `21px` / H3 `18px` / H4 `16px`（均 `w600`），代码块 `13.5px` | 正文行高 `1.65`，桌面写作版心限宽 `760px`；两模式所有输入域均采用原生 Flutter `TextField` + 下述五条 CJK IME 保护铁律 |
| 长文与 EPUB 伴读正文 | 支持无衬线屏显体与人文衬线宋/明体切换 | 默认 `17px`（`14px～22px` 可调），标题按 `1.25 / 1.5 / 1.8` 缩放 | 默认行高 `1.80`（可选 `1.65 / 1.80 / 2.00`），最大行宽 `680px～720px` |

**所见即所得与源代码双模式共用的五条 CJK IME 保护铁律（跨五端 `Windows / macOS / Linux / Android / iOS`）**：

1. **组合态零改写 `TextEditingValue`**：无论是源代码模式还是所见即所得活动块，所有监听器、块级快捷转换（如行首输入 `# `、`- `、`1. `、`- [ ] `、`> `）、格式工具栏按钮与自动补全引擎都必须先检查 `value.composing.isValid && !value.composing.isCollapsed`；处于拼音/双拼/五笔预编辑期间**严禁**对 `controller.value` 或 `controller.text` 赋值，彻底根治移动端与桌面端输入法吞字和 `TextRange` 异常。
2. **`buildTextSpan` 严格 1:1 UTF-16 长度保形着色**：所有原生 `TextField` 共用 `BlinkSyntaxTextController`，仅对 Markdown 与扩展语法（标题、`#tag`、`#private`、`[[ref|Label]]`、`**粗体**`、`*斜体*`、`~~删除线~~`、`` `代码` ``、`==高亮==`、`> 引用`、列表/待办前缀等）施加**不增删字符、不插入 `WidgetSpan`** 的 1:1 样式弱化与高亮；并显式检查 `withComposing && value.isComposingRangeValid` 为组合态子串保留原生 `TextDecoration.underline` 下划线。复选框、列表圆点、引用竖线与富媒体卡片全部置于 `TextField` 之外的兄弟组件或非聚焦渲染块中。
3. **输入法优先按键拦截**：当 `value.isComposingRangeValid && !value.composing.isCollapsed` 时，`Enter`、`Space`、`Tab`、`Esc` 与方向键一律返回 `KeyEventResult.ignored`，交由操作系统输入法优先消费选词，绝不误拆块、误跨块跳转或误提交发送。
4. **跨端自适应补全浮层（`[[`、`#`、`@`、`/`）**：
   - 仅在 `selection.isCollapsed` 且非组合态时触发本地模糊过滤；
   - **桌面端**：采用 Flutter `OverlayPortal` 锚定输入框（底部小记胶囊向上弹出、笔记编辑器贴近活动块避让 IME 候选框）；
   - **移动端**：采用固定贴合输入栏与软键盘上沿的水平候选条（热区 `≥ 44dp`）；
   - 选中候选项时通过单次原子 `TextEditingValue(text: ..., selection: ..., composing: TextRange.empty)` 完成替换。
5. **无重型富文本陷阱的类 Typora 块级架构与无损源码切换**：弃用易在移动端吞字的单画布第三方富文本编辑器，采用纯 Flutter **非聚焦块原生渲染 + 聚焦块原位无边框 `TextField` + `Ctrl/Cmd + /` 一键全文档源代码切换**，以 UTF-8 Markdown 为唯一正本实现零损耗往返转换（[DEC-033](decisions.md#dec-033)）。

圆角与尺寸基准：点击热区移动端不小于 `44×44dp`、桌面端不小于 `32×32px`；小记胶囊气泡圆角 `14px`，底部输入胶囊圆角 `18px～20px`，侧栏导航项圆角 `8px`。

<a id="semantic-html"></a>
## 3. 双表面高表现力 HTML 宿主令牌绑定与排版契约

为在保持列表 60/120fps 顺滑体验的同时释放外置/直连 AI 生成杂志级卡片与整页 HTML 报告的表现力，BLINK 执行经纯 Dart `packages/blink_sanitizer` 白名单净化后的**双表面渲染规范**（[DEC-024](decisions.md#dec-024)、[标签与生产者契约](design/data-and-sync.md#generative-html)）：

### 3.1 Surface 1：行内流卡片、伴读块与轻综述（100% 纯 Flutter 原生组件树）

由 `flutter_widget_from_html_core 0.17.4` + `fwfh_svg 0.16.1` + `fl_chart 1.3.1` + `BlinkHtmlWidgetFactory` 在五端纯原生构建（零 WebView 进程开销，适用于时间流、`super_sliver_list` 伴读正文、边注轨与轻卡片）：

- **三态主题令牌动态映射**：`packages/blink_sanitizer` 剥离全部硬编码前景/背景色；`customStylesBuilder` 将标准 HTML5 标签与受控原生组件动态绑定至当前 **Day / Sepia / Dark** 令牌，内联几何 SVG 使用 `currentColor` 与主题调色盘，切主题零闪烁。
- **杂志级原生 `<blink-*>` 组件映射**：
  - **`<blink-grid>` & `<blink-card>`（自适应 Bento 网格）**：在容器宽度 `≥ 640px` 自动排为双栏等距网格，`< 640px` 自动折为单栏纵向堆叠，底色 `surface.aiDerived` 配 `1px` `border.hairline`，零横向溢出；
  - **`<blink-metric>` / `<blink-timeline>` / `<blink-compare>` / `<blink-chart>`**：直接映射为原生数字指标卡（`tabular-nums`）、纵向演进时间轴、观点对照卡与基于 `fl_chart` 的原生折线/柱状/饼图/雷达图；
  - **跨行列合并表格、`Callout` 与 `<details>` 原文抽屉**：完整支持 `rowspan`/`colspan`（窄屏仅在表格容器内部平滑横滑）、`<aside class="callout callout-insight|tension">` 与 `<details>`/`<summary>` 折叠原文引语抽屉；
  - **`<blink-ref>` 内联可点击溯源胶囊**：渲染为紧凑圆角胶囊（`12px`、`tabular-nums`、浅 `accent.primary` 底色，移动端扩展垂直热区）；
  - **`<blink-embed kind="ai">` 只读嵌入槽（用户笔记专用）**：若目标为 Surface 1 卡片则原地展开 `surface.aiDerived` 只读卡；若目标为 Surface 2 整页则渲染紧凑预览横幅（标题、`✦ AI 派生` 来源、生成时间、摘要与唯一按钮“打开完整页面”），绝不在滚动列表内嵌套 WebView。

### 3.2 Surface 2：AI 生成整页 HTML 视图（按需零 JS 离线 CSP 沙盒）

仅在用户主动打开整页深度综述、全书视觉报告或专题仪表盘（`render_surface = "surface2_sandbox"`、`artifact_html`）时于全屏/独立窗口按需挂载：

- **五端沙盒引擎与 Linux 优雅降级**：Windows / macOS / Android / iOS 采用 `flutter_inappwebview 6.1.5`（无痕模式、Windows 通道隔离 `userDataFolder`、自定义协议 `blink-blob://` 离线供图）；Linux 采用 `desktop_webview_window 0.4.3` 动态链接系统 `libwebkit2gtk-4.1-0` + `libsoup-3.0-0`（[DEC-026](decisions.md#dec-026)），经临时回环 `127.0.0.1` 单次令牌服务下发 `Cache-Control: no-store` 与离线 CSP；若目标 Linux 宿主机缺少 WebKitGTK，或 `#private` 在 `SPK-06` 审计中未满足零落盘条件，自动优雅降级为 **Surface 1 原生视图（`view_html`）** 并在顶栏提供“在系统浏览器打开本地导出 `.html`”按钮。
- **零脚本、零外链与实时主题注入**：浏览器强制执行 `default-src 'none'; script-src 'none'; style-src 'unsafe-inline'; img-src blink-blob: data:; font-src 'self' data:`，物理阻断全部外网请求；宿主切换 Day / Sepia / Dark 时通过实时注入 `--blink-*` CSS 变量表瞬间同步配色，无需重新生成 HTML。
- **零 JS `<blink-ref>` 原生回跳**：页面内所有 `<blink-ref>` 已由 `packages/blink_sanitizer` 编译为 `<a class="blink-ref" href="blink-ref://<kind>/<id>?anchor=...">`，由 WebView 导航拦截回调直接交回 Flutter 唤起一致的**原文预览浮层 / 半屏抽屉**。

### 4.1 小记：闪念胶囊与聊天记录式瞬时记录（Memos）

  - **气泡快捷操作**（桌面悬停或点 `⋯`、移动点 `⋯`）：**编辑**（支持主动开启或取消 `🔒 私密` 状态，取消时自动清除正文独立 `#private` 标签并将检索索引迁回常规区）、**转为笔记**（无损新建一篇关联长笔记并自动带 `来源小记` 反链跳转编辑，原小记气泡完整留在聊天记录中，`INV-01`）、**复制**、**移入回收站**（本地永久保留，直至手动还原、单条彻底删除或经二次确认清空回收站）。
  - 后续 M7 语音与纸质书页拍照小记沿用同一胶囊形态，展示原生音频播放条 / 书页原图缩略图与派生转写/引文槽位。
- **底部常驻胶囊输入框**：
  - **桌面端**：居中限宽 `720px` 的 `18px` 圆角胶囊框，支持 1～6 行自动增高、未发送草稿崩溃恢复、`Ctrl/Cmd + Enter` 发送与 `Enter` 换行；左下角仅放 4 个直观图标（`# 标签`、`☑ 待办`、`📎 附件`、`🔒 私密`），右下角为唯一主按钮 `发送`；键入 `#`/`[[`/`/` 时向上弹出 `OverlayPortal` 候选列表。

### 4.2 笔记：文档列表与类 Typora 所见即所得编辑器（Notes）

- **资源侧栏（桌面常驻 / 移动端为主列表页）**：顶部提供唯一主按钮 `+ 新建笔记`，下方为 `全部` / `🔒 私密` / `回收站` 紧凑切换、按最近更新时间排序的笔记列表（自动从首行提取标题或显示“无标题笔记”，配单行纯文本摘要、相对时间与私密锁标）及底部标签筛选。
- **类 Typora 所见即所得 + 源代码双模式编辑器**：
  - **顶部精简工具栏**：桌面端融入窗口顶栏拖拽空白区并为右上角窗口控制按钮留出避让间距，左侧显示自动保存状态（`已保存` / `保存中…`），中间提供常用格式快捷钮（标题、加粗、斜体、高亮、待办、列表、引用、代码块）与 `🔒 私密`（支持主动开启与取消；取消私密时自动清除正文独立 `#private` 标签并将检索索引迁回常规区）/ `📎 附件`，右侧固定 **`所见即所得` / `源代码`** 切换按钮（快捷键 `Ctrl/Cmd + /`）与 `⋯` 更多菜单（复制 Markdown、移入回收站）；移动端点击笔记或 `+` 后推入全屏专注编辑页，顶栏仅保留 `< 返回`、保存态、模式切换图标与 `⋯` 菜单。
  - **所见即所得模式（默认）**：文档居中限宽 `760px`，非聚焦块隐藏全部 Markdown 符号并以原生排版组件呈现（H1–H6、粗斜体/删除线/高亮/行内代码、可点选待办框、无序/有序列表、引用竖线、高亮提示框、代码块、水平分隔线、表格、折叠块、AI 派生只读卡）；点击任意块原位进入无边框 `TextField` 编辑，并支持 `# `、`- `、`1. `、`- [ ] `、`> `、`---`、```` ``` ```` 等实时块级转换以及 `Enter` 拆块/续写列表、段首 `Backspace` 退化/合并、上下键顺滑跨块移动（全部严格守卫 CJK IME 非组合态）。
  - **源代码模式**：单框全文档语法着色编辑，随时与所见即所得无损互切；默认打开模式可在 `设置 → 常规与外观` 中调整并持久化。
  - **回收站保护**：本地回收站不设自动清理期限（[DEC-034](decisions.md#dec-034)），查看已删除小记或笔记时进入只读态，顶部提示内容将一直保留直至手动处理，并提供单条 `还原` / `彻底删除` 与需二次确认的 `清空回收站` 操作。

### 4.3 待办、附件管理与全局搜索（Tasks, Files & Search）

- **待办（Tasks）**：自动汇总所有小记与笔记中的 `- [ ]` 清单项，勾选状态双向同步回原小记/笔记正文。桌面端左侧资源栏提供 `全部待办`、`待完成`、`稍后处理`、`已完成`、`已取消` 分组计数及 `仅看私密 (🔒)` 开关；移动端以极简顶部分段筛选呈现；每条待办右侧保留来源跳转按钮，点击直接定位到原小记或原笔记。
- **附件（Files）**：桌面端左侧独立入口配资源栏（`全部附件`、`图片`、`文档`、`音频`、`其他`、`未引用附件`、空间占用与 `清理未引用`，右上 `+ 导入`）；移动端归入 `设置 → 附件管理` 子页以保持底栏简洁。条目展示直观的文件类型、体积、引用它的笔记/小记胶囊（可点击跳转）、关联到新笔记与导出副本动作，技术指纹信息退居次要提示。
- **全局搜索（`Ctrl/Cmd + K` / 移动顶栏搜索图标）**：支持中英文单字、词组与标签即时检索，提供 `仅常规范围 / 含 #private` 切换，结果清晰标出 `小记`、`笔记`、`待办` 与 `🔒 私密` 标识，点击直接跳至对应条目。

### 4.4 飞书式分类设置页（Settings）

桌面端（`≥ 960px`）采用与其余模块一致的**左侧设置分类资源栏 + 右侧单项详情面板**（限宽 `720px`）；窄屏平板（`600–959px`）通过抽屉或顶部分类条切换；移动端（`< 600px`）采用干净的**分类列表 → 推入单项详情页**二级导航（额外提供 `附件管理` 入口）。彻底告别单页堆叠长表单：

1. **常规与外观**：主题外观（`跟随系统` / `日间` / `暖纸` / `夜间`）、笔记默认编辑模式（`所见即所得` / `源代码`）、桌面端关闭窗口行为（`隐藏到托盘` / `直接退出`）及配置文件异常恢复提示。
2. **存储与备份**：
   - 桌面端展示 `数据文件夹`（默认系统“文档”目录 `<Documents>\blink[-dev]`，源码构建隔离于 `.local/blink-dev/vault`），支持选择目录、切换、恢复默认，以及当路径位于 OneDrive 目录内时的温和非阻塞提示；移动端简洁说明数据仅存本机私有存储且不参与系统自动云备份；
   - 展示小记/笔记/待办/附件数量与占用空间、通道隔离标识；
   - 提供桌面端 `Markdown 自动导出` 状态与 `立即导出 Markdown`，以及 `立即备份数据`、`重建搜索索引` 维护动作。
3. **多端同步**：展示当前同步状态与冲突处理入口，平铺清晰的三组配置——① **局域网直连服务**（桌面端开关、端口、局域网/Tailscale 地址、一次性配对码与已配对设备管理）；② **局域网配对与自动同步**（自动同步开关、局域网扫描、手动配对与立即同步）；③ **云端加密同步（WebDAV / S3）**（协议与端点配置、仅存系统密钥库的凭据、端到端加密恢复密钥生成/导出/导入，以及默认开启的 **`私密内容不上传云端`** 开关）。
4. **关于 BLINK**：展示品牌标识、产品名、通道徽标（`正式通道` / `DEV 开发通道`）、版本、通道、安装标识、提交版本与 `应用配置目录`（与 `数据文件夹` 清晰区分）。

后续 M6 接入外置 AI 扩展（CLI / MCP / Skills）与可选直连 AI 接口时，直接在设置分类资源栏新增对应分类项，保持每个详情面板克制专注。

### 4.6 全局连接、同步、解析与渲染显式状态规范

所有异步、网络与降级边界均按统一状态契约呈现，严禁把异常或未就绪状态伪装成“暂无内容”（`INV-11`）：

| 状态场景 | 界面呈现位置与视觉符号 | 文案与用户可执行动作 |
| --- | --- | --- |
| **常态未配置 / 已同步** | 桌面图标栏底部同步圆点（灰/绿）+ `设置 → 多端同步`（不占用全局顶部横栏） | 悬停或进入同步设置可查看“未配置同步”或“已同步”详情及一键同步入口 |
| **离线待传（Offline Pending）** | 顶部安静琥珀状态条 + 图标栏琥珀圆点 | 提示“当前离线 · N 项待同步”，本地记录、搜索与阅读 100% 可用，联网后自动同步 |
| **对端离线 / 休眠（Peer Asleep）** | 顶部柔和琥珀状态条 | 提示“对端离线 · N 项已排队待同步”，提供前往“云端加密同步”设置入口 |
| **队列同步中（Syncing）** | 顶部轻量旋转同步弧线 + 图标栏蓝点 | 标明同步通道与剩余项数，绝不锁定输入与页面切换 |
| **同步冲突待处理（Conflict）** | 顶部红色提示条“N 条同步冲突待处理” + 图标栏红点 | 并排/上下对比双本差异，提供“保留本机”“采用远端”“合并保存后确认”，裁定前两份原文完整保留 |
| **私密隔离与本地闭锁（`#private` / `privacy_blocked`）** | 条目青绿锁标 `🔒 私密`；触发闭锁时单行提示 | 说明“仅本机与受控本地模型可访问，不上传云端”；本地端点未就绪时明确提示并引导检查配置，绝不回退云端 |
| **扫描版 PDF 无文本层（`missing_ocr`）** | PDF 顶栏下方浅暖色可收起提示条 | 提示“当前页面为扫描图像、暂无可选中文字：仍可直接框选区域记边注，或通过外部 OCR 补齐检索” |
| **Linux 缺失 WebKitGTK 降级** | 整页综述顶部浅灰单行提示 | 提示“当前系统未安装 WebKitGTK 4.1，已自动切换为原生卡片视图”，右侧提供“在浏览器打开本地导出页” |
| **抓取 / 解析 / 磁盘错误（Error）** | 条目内嵌浅红底单行说明条（配感叹号图标） | 写明具体原因（如站点需要登录、目录通道不匹配、磁盘空间不足），提供“重试”“浏览器打开”或“前往设置” |
